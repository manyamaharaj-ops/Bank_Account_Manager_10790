# Simple Bank Account Manager

A console-based Bank Account Management System developed using Java.

## Features
- Create new bank accounts with unique Account IDs.
- Deposit money into accounts.
- Withdraw money with balance validation.
- Search accounts by account holder name.
- Display accounts sorted by balance (highest to lowest).
- Store account records using ArrayList.
- Save account data using File Handling.

## Technologies Used
- Java
- ArrayList
- Linear Searching
- Sorting
- File Handling

## Concepts Used
- Object-Oriented Programming (OOP)
- Data Structures and Algorithms (DSA)
- Classes and Objects
- Methods
